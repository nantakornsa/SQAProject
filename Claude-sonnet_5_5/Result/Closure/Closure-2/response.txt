The test below calls `testTypes` from `TypeCheckTest` the same way the triggering test does. I have not compiled or run it against the buggy and fixed versions.

I could not reproduce the whole of `TypeCheckTest` here. Instead, the test is a subclass in the same package, so it can reach the package-level `testTypes` helper. The catch is that the subclass also re-runs every inherited `TypeCheckTest` test. If you would rather keep it isolated, paste the single test method into `TypeCheckTest` itself.

On the buggy version, `interfaceType.getImplicitPrototype()` returns null for an interface that extends non-existent types, which causes the `NullPointerException`. On the fixed version, it should only report the two "Unknown type" warnings.

```java
package com.google.javascript.jscomp;

public class TypeCheckInterfaceExtendsNonExistentRegressionTest
    extends TypeCheckTest {

  public void testRegressionInterfaceExtendsNonExistentInterfaces()
      throws Exception {
    String js = "/** @interface \n" +
        " * @extends {nonExistent1} \n" +
        " * @extends {nonExistent2} \n" +
        " */function A() {}";
    String[] expectedWarnings = {
      "Bad type annotation. Unknown type nonExistent1",
      "Bad type annotation. Unknown type nonExistent2"
    };
    testTypes(js, expectedWarnings);
  }
}
```
