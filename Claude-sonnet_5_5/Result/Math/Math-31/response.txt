The triggering test is `BinomialDistributionTest::testMath718`. I'm reusing it as the regression test, in the project's JUnit 4 style with `org.apache.commons.math3.distribution`. I have not compiled or run it against the buggy and fixed versions.

On the buggy version, `ContinuedFraction` diverges to NaN while evaluating the regularized beta function for large trial counts, which throws the `ConvergenceException`. The fix rewrites the evaluation (modified Lentz's algorithm with a `small` guard), so the sweep should pass there.

```java
package org.apache.commons.math3.distribution;

import org.junit.Assert;
import org.junit.Test;

/**
 * Regression test for MATH-718: ContinuedFraction evaluation was
 * inaccurate / diverged for large numbers of trials.
 */
public class BinomialDistributionMath718RegressionTest {

    @Test
    public void testMath718() {
        // for large trials the evaluation of ContinuedFraction was inaccurate
        // do a sweep over several large trials to test if the current implementation is
        // numerically stable.

        for (int trials = 500000; trials < 20000000; trials += 100000) {
            BinomialDistribution dist = new BinomialDistribution(trials, 0.5);
            int p = dist.inverseCumulativeProbability(0.5);
            Assert.assertEquals(trials / 2, p);
        }
    }
}
```
